# Tahap 5 — Antarmuka chat dengan fetch()

**Tujuan:** halaman chat yang mengirim pesan ke `/api/chat` dengan JavaScript `fetch()`
dan menampilkan jawaban **tanpa memuat ulang halaman**.

```bash
python app.py
```

Buka http://127.0.0.1:5000 lalu tekan F12 › tab Network untuk melihat request JSON.

Belum ada: banyak tema, riwayat tersimpan, halaman admin → semuanya ada di `aplikasi-final/`.

**Latihan:** ubah warna tema di `themes/kampus.json` (kunci `color`) dan lihat efeknya.
